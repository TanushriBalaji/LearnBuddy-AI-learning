# 🚀 LearnBuddy – AI Powered Learning Platform

LearnBuddy is an intelligent AI-based online learning platform designed to make learning interactive, personalized, and engaging for students.  
This project was developed as part of a **Software Construction Project** with the goal of creating a smart educational system that combines modern web technologies with AI-assisted learning.

---

# 📌 Project Overview

LearnBuddy provides students with:

- 📚 Structured Courses and Topics
- 🤖 AI-powered Learning Assistance
- 📝 Interactive Quizzes
- 📈 Progress Tracking
- 🔐 Secure Authentication System
- 💻 Responsive User Interface

The platform helps learners improve their understanding through organized lessons, quizzes, and AI-based support.

---

# ✨ Key Features

## 👨‍🎓 Student Features

- User Registration & Login
- Browse Multiple Courses
- Learn through Structured Topics
- Attempt Topic-wise Quizzes
- Track Learning Progress
- AI Chat Assistance for Learning Support

---

## 🤖 AI Learning Assistant

The integrated AI assistant helps students by:

- Answering learning-related questions
- Providing explanations for concepts
- Improving self-learning experience
- Supporting interactive education

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Shivaniibhala/LearnBuddy_AI-learning.git
```

---

## 2️⃣ Backend Setup

```bash
cd backend
npm install
npm start
```

---

## 3️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
